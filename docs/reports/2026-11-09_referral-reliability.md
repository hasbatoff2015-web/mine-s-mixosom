# Устойчивость реферальной программы

## Goal

Убрать гонки, из-за которых награда, кит или приглашение могли сохраниться не в том порядке или потерять учёт после сбоя базы.

## Result

Исправления в той же ветке `cursor/referral-program-complete-8299` и PR #145. Правила наград не менялись. `main` не обновлялся. VPS и Яндекс Игры не выкладывались.

## Implemented

- Запись фаз VIP/PREMIUM идёт одной очередью на UUID. `referral_rewards.revision` принимает только более новую ревизию. Остановка сервера дописывает последний снимок. Повтор после ошибки базы берёт текущую память.
- Выдача `referral_starter` для одного UUID выполняется по одной. `markKitClaimed` вызывается после успешного сохранения инвентаря или по уже лежащей квитанции.
- `accept` при конфликте `referral_relations_invitee_unique` читает существующую связь и отвечает `already`. Другой `23505` остаётся ошибкой базы.
- После неудачного `onJoin` одна цепочка повторов поднимает трекер, когда база снова отвечает. Время без трекера не начисляется.
- В снимке персонажа хранится список отслеживаемых предметов выдачи. Resource Ledger считает их по `referral:{id}` один раз. Следующий запуск восстанавливает пропущенную запись учёта.
- Код из payload Яндекса очищается, только когда меню сервера показывает уже принятую связь.

## Tests

- `tests/server/referral-reliability.test.ts`: устаревшая ревизия, задержанное сохранение, два одновременных claim, ошибка сохранения, восстановление трекера, повторный учёт ресурсов.
- `tests/server/referral-postgres.integration.test.ts`: две транзакции проходят пустое чтение и оставляют одну связь.
- `tests/server/referral-activity.test.ts`: управляемое перемещение даёт секунду.
- `tests/referral-menu.test.ts`: payload остаётся при ошибке и снимается после принятой связи.
- `tests/server/referral-world.test.ts`: потерянный файл Resource Ledger восстанавливается один раз, предметы не дублируются.

- `npm run build`, `npm run build:server`, `npm run build:admin`: прошли.
- Реферальные тесты, включая PostgreSQL с `FC_TEST_DATABASE_URL` на локальной базе `fc_referral_test`: прошли. Миграции до `0012`.

Причины: нет модуля Pillow, в `public/audio/sfx` 27 файлов вместо ожидаемых 26, визуальные тесты (`readMeshSkyLight`, геометрия) и таймаут `stage6-backup` T5. ## Known limits

Живой SDK Яндекс Игр и production-база по-прежнему не прогонялись. Эвристика активности не стала античитом. Незаписанное окно секунд при падении процесса по-прежнему может потеряться.
