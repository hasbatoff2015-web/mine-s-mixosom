# Меню «Бонус за друга»

## Goal

Поднять заголовки экранов «Друзья» и рефералки, сделать реферальное окно компактнее и убрать из него пояснения и неактивную кнопку копирования ссылки. Серверная рефералка не меняется.

## Result

Оба экрана используют общий класс `mc-social-menu-body`. Раздел называется «Бонус за друга». Приглашения кланов остаются «Приглашения». Логика кодов, наград, кита и Yandex SDK на месте. `main` не обновлялся. VPS и архив Яндекс Игр не выкладывались.

## Implemented

- Кнопка в «Друзьях», заголовок экрана и `menuTitle('friends-invites')` говорят «Бонус за друга».
- `activityNote` и `guestWarning` больше не рисуются. Поля `ReferralMenuState` и серверные строки сохранены.
- Без URL кнопка «Скопировать ссылку» имеет `hidden`. `applyLocalReferralLink()` записывает `data-referral-value`, снимает `disabled` и `hidden`, когда SDK даёт адрес. `.mc-ah-btn[hidden]` принудительно `display: none`, поэтому `inline-flex` её не показывает.
- Код, форма принятия, счётчики, награды, список и стартовый набор собраны в блоки с внутренним промежутком `2px * scale`.
- `.mc-referral-list` имеет `min-height: 0` и `max-height: 120px * scale` и стоит после `.mc-menu-list`, поэтому пустая минимальная высота списка не возвращается. Строки списка `flex: none`, иначе flex сжимал их внутри ограниченной высоты.

## Architecture decisions

Смещение заголовка давал `padding-top: max(48px, 26px * scale)` у `.mc-menu-body`. Кнопки назад и закрытия уже стоят абсолютно в `.mc-menu-chrome` и не занимают поток. Для двух социальных экранов отступ стал `max(48px, 20px * scale)`, промежуток тела — `4px * scale`. Глобальные `.mc-menu-body`, `.mc-menu-list` и ширина 248 не менялись. `menuLogicalHeight('friends-invites')` остаётся 340: на проверенных размерах панель помещается, а меньшее значение увеличило бы масштаб.

| Viewport | Друзья | Бонус за друга |
| --- | --- | --- |
| 888×1180 | scale 3, зазор заголовка 0, кнопки внутри панели | scale 3, один приглашённый высотой 85px без пустого слота, ссылка скрыта |
| 856×844 | scale 3, зазор 0 | scale 2, зазор 8px, поле и «Принять приглашение» в одной строке |
| 390×844 | scale 1, панель 248px, зазор 6px, кнопки друзей внутри | scale 1, зазор 6px, поле и кнопка принятия внутри панели |

Двенадцать приглашённых: видимая высота списка `120px * scale`, `scrollHeight` больше неё (1096px при scale 3). Строки не накладываются.
