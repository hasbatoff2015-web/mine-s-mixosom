# Ошибки внешних серверов, логотипы и публичные адреса

Дата: 2026-10-23. Ветка от `origin/main` `4c0c24a2eb9537234d036c03f2b2f7819bb9d4f5`. Релиз, загруженный в черновик Яндекса: `c917ed7a5efdcac06934c2190cc86ed3386b1b8f` (предок текущего main). PR #129 не переносился.

## Goal

Черновик Яндекс Игр открывает меню, но три сервера выглядят как «оффлайн», логотипы не рисуются, а заявка CSP на `megacraft.agariobrainrot.ru` отклонена: игра не объясняет сбой внешнего соединения и не предлагает повтор. Нужно разделить недоступность хоста и реальное выключение сервера, починить пути картинок внутри ZIP и перестать ходить из production на localhost для Выживания и Мирного.

## Root Cause

Подтверждено кодом на `origin/main`, не гипотезой.

1. `fetchStatusAt` в `src/net/AnarchyClient.ts` ловил любую ошибку и HTTP-неуспех и возвращал `{ reachable: false, online: 0, maxPlayers: 0 }`. Timeout, обрыв, HTTP 500 и битый JSON выглядели одинаково.
2. `onlineServerRows` в `src/ui/menuModel.ts` рисовал `reachable: false` как «оффлайн». Нулевой онлайн при живом `/status` тоже мог потеряться только если запрос падал. Пустой, но живой сервер (`online: 0`) и был available, однако сбой проверки назывался выключенным сервером.
3. `Game.showOnlineServerList` ждал все три запроса и только потом открывал экран. `connectOnlineServer` при ошибке сокета показывал toast «Сервер недоступен» и сразу возвращал список, где сообщение пропадало. Кнопки «Повторить» не было.
4. Логотипы были абсолютными `/ui/server-logos/...`. Во вложенном каталоге Яндекса браузер ищет их в корне origin, не в ZIP. Тот же класс ошибки был у `url('/ui/...')` и `url("/fonts/...")` в CSS: Vite `base: './'` такие пути не переписывает.
5. Production задаёт только `VITE_ANARCHY_URL`. `clientUrlForServer` для Выживания и Мирного всегда брал `127.0.0.1:2568` и `:2569`. Это адрес машины игрока. Публичного nginx-маршрута для этих режимов в задании нет, и его нельзя выдумывать. Любой непустой `?server=` ещё и сбрасывал Anarchy с `VITE_ANARCHY_URL` обратно на localhost.

Живая проверка 23 октября 2026, 20:11 (Екатеринбург): `GET https://megacraft.agariobrainrot.ru/status` вернул HTTP 200, `Access-Control-Allow-Origin: *`, `ready: true`, `online: 1`, `maxPlayers: 300`. Это не доказывает, что CSP Яндекса уже разрешает хост. Код сервера и так отдаёт этот заголовок на `/status`.

## Result

Игрок видит проверку, понятный сбой и рабочую кнопку «Повторить». Анархия в production остаётся на `wss://megacraft.agariobrainrot.ru`. Выживание и Мирный без своих публичных URL не обращаются к localhost и подписаны «Сервер пока недоступен». Три логотипа и шрифты/фон меню грузятся из каталога сборки, в том числе из вложенного пути. CSP не подавался и не считается одобренным.

## Implemented

- Типизированный результат проверки: `checking`, `available`, `unavailable` (`timeout` | `network` | `http` | `invalid_response`), `not_configured`, внутренний `aborted`.
- `ServerStatusSession` хранит одно поколение и `AbortController`. Отмена и более новый запрос не дают старому ответу обновить UI. Abort не показывается как ошибка игрока.
- Экран открывается сразу со статусом «Проверка…». Обновляются строки, общая ошибка и кнопки, без пересоздания формы ника.
- «Повторить» снова вызывает `fetch`, на время проверки блокируется и не запускает второй параллельный запрос.
- Неоткрывшийся WebSocket заменяет loading на текст «Не удалось подключиться к игровому серверу. Проверьте интернет или попробуйте позже» с «Повторить» и «К списку серверов». Автоматического цикла нет.
- `VITE_SURVIVAL_URL` и `VITE_PEACEFUL_URL` необязательны. Status URL по-прежнему выводится из WSS: `wss` → `https`, путь `/status`.
- `?server=` только выбирает начальную карточку. `?anarchyUrl=`, `?anarchyHost=` и `?anarchyPort=` по-прежнему переопределяют только эту карточку. `?anarchyUrl=` по-прежнему не подменяет status.
- `serverLogoUrl()` использует тот же `resolveAssetUrl` / `BASE_URL`, что меню и чат.
- Сборка переписывает в CSS корневые `url(/ui|fonts|textures|audio/...)` на `../...` относительно `assets/*.css`. `/sdk.js` не трогается.

## Architecture Decisions

Сеть не владеет DOM. UI не выбирает адреса. Один и тот же `clientUrlForServer` / `statusUrlForServer` служит и проверке, и WebSocket. `Game` решает, когда запрашивать и какой ответ ещё актуален. Отдельный менеджер подключений не заводился. Протокол, prediction и серверные миры не менялись.

Почему «оффлайн» врал: `reachable: false` означало «проверка не удалась», а подпись утверждала, что сервер выключен. Нулевой онлайн при HTTP 200 остаётся счётчиком `0 / N`.

Почему Retry настоящий: клик, если проверка не идёт, ставит «Проверка…», вызывает `ServerStatusSession.load()` и по новому ответу меняет подписи. Повторный клик во время проверки отбрасывается, предыдущий `fetch` при новом разрешённом запросе отменяется.

Почему localhost нельзя в production: `127.0.0.1` на телефоне игрока — это сам телефон. Порты 2568 и 2569 живы на VPS, но снаружи до них нет подтверждённого HTTPS/WSS. Production при `import.meta.env.PROD` выкидывает ветку локальных пресетов; в собранном JS `localPresetsAllowed` свернут в `return false`. Явный `?anarchyHost=` для локальной проверки сохранён.

Браузер с WebGL и черновик Яндекса в этой среде не прогонялись. Это не замена ручной проверке меню.

По HTTP, не через `file://`:

- корень `dist`: `index.html`, три PNG, фон, шрифт, CSS — HTTP 200;
- тот же `dist` по пути `/yandex-draft/game/`: те же файлы, включая три PNG с сигнатурой PNG, CSS и JS — HTTP 200;
- в CSS нет `url(/ui/` и `url(/fonts/)`, есть `url(../ui/...)` и `url(../fonts/...)`;
- `index.html` содержит `<script src="/sdk.js"></script>` и относительный `./assets/...`;

- `dist/server` нет. Путей с пробелами и кириллицей нет.

Поведение кликов, повтора и смены экрана проверено в happy-dom, не в настоящем браузере.

## Known Issues

- Публичные WSS Выживания и Мирного не существуют. Карточки честно недоступны, пока не появятся маршруты и env.
- CSP Яндекса не одобрен. Пока портал режет `connect-src`, Анархия в черновике тоже будет «Не удалось связаться», даже если VPS жив. Это ожидаемо и не диагноз «сервер выключен».
- Обрыв уже начатой игры по-прежнему показывает toast «Сервер недоступен» и возвращает в главное меню. Это не экран первичного подключения.
- `?anarchyUrl=` по-прежнему меняет только сокет выбранной карточки. Status остаётся на host/port, если нет `?anarchyStatus=`.

## Инфраструктура перед повторной заявкой CSP

2. В игре при заблокированном хосте видно сообщение и «Повторить», и повтор реально меняет состояние.
3. В заявке по-прежнему только подтверждённые хосты. Сейчас это `megacraft.agariobrainrot.ru` для HTTPS `/status` и WSS Анархии. Не добавлять `/survival` и `/peaceful`, пока nginx их не обслуживает.
