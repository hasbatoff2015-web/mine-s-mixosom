# Goal

Replace Frontier Cubes’ oscillator beeps with a light, cached, sample-based core SFX system (~20–25 source files, pitch/volume variation) without a second audio stack, without shipping Minecraft audio, and without tying simulation to sound duration.

# Git baseline / branch

- Baseline: `origin/main` = `3c9cf45` (Merge PR #8 creeper/fence/plants/tooltip/RU).
- Working branch: `cursor/core-audio-sfx-0b75` created from that `main` (detached Cloud HEAD was already `main`).
- No force-push, no `main` updates, no rebase onto foreign history.

# Previous AudioManager

`src/core/AudioManager.ts` was a square-wave `playTone` helper. `Game.ts` called it for pickup, melee, mining, place, lever/button/door, eat, bow, explosion (up to 2 tones/tick), flint, bucket, minecart. Pause/resume/mute/masterVolume and Yandex lifecycle already existed. There were no files under `public/audio/`.

# Sound event architecture

Canonical `AudioManager` now exposes `play(event)`, `playAt(event, position, listener)`, `playBlock(action, blockId, position, listener)`. Events are `SoundEventId` in `src/audio/soundEvents.ts`. Catalog (`src/audio/soundCatalog.ts`) owns filenames, volume, pitch range, positional flag, max distance, bus, concurrency, priority. Gameplay never names MP3s.

# Block sound groups

`BlockDefinition.soundGroup` is inferred in `src/blocks/soundGroups.ts` (stone / wood / dirt / sand / wool / glass). Air/water/lava are silent. One family drives hit/break/place/step. No `BlockId` switch in `Game.ts`.

# Sample budget

26 short mono MP3 (22.05 kHz, 48 kbps, ~0.11 MiB): 11 material variants + 15 named one-shots including optional `water_splash`. Regenerated by `npm run audio:generate-sfx`.

# WebAudio loading/cache

Boot `preload()` fetches all catalog files concurrently, decodes once into an `AudioBuffer` map, reuses buffers. No `HTMLAudioElement` per event. Decode/load failures never throw; DEV warns once per missing file/event; production stays silent. `playTone` remains DEV fallback if a buffer is not ready.

# Positional audio

World events use a one-shot PannerNode (`equalpower`, linear distance) plus skip-beyond-`maxDistance`. Player-local: eat, drink, pickup, hurt, bow shoot, and **player footsteps** (`playBlock(..., { positional: false })`). Catalog `block.step.*` remains positional for future mob callers. Nodes disconnect on `ended`. No permanent sound objects.

# Mining / break / place

`nextMiningSound` (4-tick interval, Java 1.8-style) while progress advances. Instant/creative break emits only `break`. Successful place uses the block’s group. Failed place is silent. Explosions do not play 100 block-break voices.

# Footsteps

`advanceFootsteps` accumulates grounded horizontal travel (not frames). Sprint uses a shorter stride. Flying / water resets. Sample comes from the block under the feet. **Player footsteps override `positional: false`** so they stay centered in first-person; they previously used a world PannerNode at the block under the camera and sounded behind/below the listener. World `block.step.*` callers (future mobs) keep the catalog's positional default.

# Explosion

TNT, creeper, and TNT minecart enqueue the same queue. `onResolved` plays `explosion` with nearby/per-tick dedupe (max 2 / tick, 1.5-block radius). Higher priority than block hits.

# Combat / Bow / Arrow

Accepted melee and accepted player-arrow mob hits: `combat.hit`. Ignored hurt-resistance clicks stay silent. Bow **release** (not charge): `bow.shoot`. Collision-geometry block embed (player + skeleton): `arrow.hit` once. Vegetation does not collide, so it does not click.

# Inventory / food / interaction

Pickup sound only when `accepted > 0` (drops and pickable arrows). Eat vs drink from `consumableSoundEvent`. Door open/close from actual state. Chest open/close on inventory transition. Lever/button share `click` with ON/OFF pitch. Flint: `fire.ignite`. Water bucket: `water.splash`.

# Lifecycle

Existing `pause()` / `resume()` / `setVolume` / `setMuted` unchanged. `PLAYING` resumes context; other lifecycle states suspend. AudioContext is still gesture-lazy. Simulation does not read sound duration.

# Performance

No per-frame audio allocations. Shared buffers. Global cap 20 voices; per-bus caps; explosion steal. Far events skipped. Archive impact is tens of kilobytes.

# Asset licensing strategy

Production MP3 are original procedural synthesis for Frontier Cubes (`scripts/generate-core-sfx.mjs`). Documented in `docs/AUDIO_ASSETS.md`. Minecraft sounds are local A/B only.

# Minecraft local reference extractor

`scripts/extract-minecraft-reference-sounds.mjs` / `npm run audio:extract-reference`:

1. `%APPDATA%\.minecraft\assets` (plus Linux/macOS defaults, `--assets`).
2. Prefers `1.8.json`, else newest `1.8.x`.
3. Resolves logical keys through the index SHA-1 map (hashes not stored in the repo).
4. Copies friendly `.ogg` into `.local/minecraft-reference-audio/` (gitignored).

Cloud agents without a Windows Minecraft install cannot extract; that is expected. The runtime does not load those files.
