# Stage C1: проверка подписи Яндекса остановлена

Дата: 2026-10-15

## Goal

Понять, можно ли по официальному `player.signature` получить устойчивый id игрока, и не включать вход, если нельзя.

## Result

Вход через Яндекс выключен. Сервер умеет отвергнуть битый конверт и неверную HMAC-подпись. Верная подпись покупки не становится личностью игрока. Объект `{ verified: true }` по-прежнему не считается криптографической проверкой. База с `deploymentId=dev` не читает и не пишет scope `prod`.

## Что сказано в документации

Страница игрока: https://yandex.com/dev/games/doc/en/sdk/sdk-player

- `ysdk.getPlayer({ signed: true })` отдаёт `player.signature`.
- Формат: `<signature>.<profile data>`, обе части base64.
- Секрет игры появляется после подключения покупок, на вкладке In-app purchases → Settings. В git его нет.
- Лимит: 20 вызовов `getPlayer` за 5 минут.
- `ysdk.auth.openAuthDialog()` только по явному действию игрока.
- `getUniqueID()` и `isAuthorized()` описаны как методы клиента.

Страница покупок: https://yandex.com/dev/games/doc/en/sdk/sdk-purchases

- HMAC-SHA256 считается по декодированным байтам второй части.
- Опубликованный пример с ключом `t0p$ecret` сходится.
- JSON покупки содержит `algorithm`, `issuedAt`, `data.token`, `data.product`. Это не профиль игрока.

## Чего в документации нет

Имена полей JSON внутри подписанного профиля игрока. Нет официального вектора «секрет + signature игрока + unique id». Нет описания, есть ли в профиле срок действия. Нет подписанного признака «аккаунт авторизован», отличного от анонимного гостя Яндекса.

Поэтому C2, C3 и C4 не делались: нет кнопки входа, нет пакета join с подписью, нет выдачи UUID по Яндексу.

## Конфигурация

`FC_YANDEX_AUTH_ENABLED=1` и `FC_YANDEX_AUTH_SECRET` не включают вход. Без секрета причина `missing_secret`. С секретом причина `profile_schema_unverified`. Секрет в лог не пишется. Обычный сервер без этих переменных стартует как раньше.

## Tests

`tests/server/yandex-verifier.test.ts` использует опубликованный вектор покупки только как проверку HMAC и отвергает его как профиль. Самодельный JSON с `uniqueID` после верной подписи тоже не создаёт личность. Это не официальный вектор игрока.
